# 🖼️ Image Processing Studio (GUI Application)

## 📌 Project Overview

This project is a desktop-based Image Processing application built using **Python, OpenCV, and Tkinter**.

It allows users to open an image, apply various classical image processing filters, and visually compare the original and processed images side by side.

The goal of this project is to demonstrate practical implementation of fundamental Computer Vision and Image Processing techniques.

---

## 🎯 Objectives

* Build an interactive GUI for image processing
* Implement classical filtering techniques
* Apply edge detection algorithms
* Perform morphological operations
* Implement basic image segmentation methods

---

## 🖥️ Application Features

### ✅ Image Handling

* Open image from local machine
* Display original and processed images
* Reset to original image
* Save processed image

---

## 🎨 Implemented Filters & Techniques

### 🔹 Smoothing Filters

* Low Pass Filter (Gaussian Blur)
* Mean Filter
* Median Filter

### 🔹 Edge Detection

* High Pass Filter
* Roberts Edge Detector
* Prewitt Edge Detector
* Sobel Edge Detector

### 🔹 Morphological Operations

* Erosion
* Dilation
* Opening
* Closing

### 🔹 Segmentation & Detection

* Thresholding Segmentation
* Region Split and Merge Segmentation
* Hough Circle Transform
